One word for your Wi-Fi: **peekaboo**. Home Wi-Fi keeps playing peekaboo — full bars one second, gone the next, back again for no reason, gone again the moment you actually need it. The program writes that one word to `/output/entry.txt` for make.fun's "One Word for Your Wi-Fi" bounty.

## Run it

```sh
node main.ts
```
